name: output-verification
description: Use when ensuring output files exist and match specified schemas.
---
1. Check that the required output files exist in the specified directory.
2. For each output file, verify that it matches the schema defined in the task specification.
3. If any output file is missing, create it according to the specified schema.
4. If any output file does not match the schema, correct it to ensure compliance.
5. Confirm that all required fields are present and correctly formatted.
6. After verification, run any necessary tests to ensure the outputs are correctly generated.
7. Review the task specification for any additional output requirements or examples.
